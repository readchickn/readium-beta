Readium UI previews

Ten looks for the same Readium page. Each one is the full live site with a different style — log in and try chat, rooms, games and settings in any of them. Pick a favorite and tell Muse which one.

v1-mono — Black & White
Pure monochrome: black on white, sharp square corners, no color, no animations. Kindle e-ink friendly.

v2-colorsoft — Colorsoft
Kindle Colorsoft: muted desaturated colors, warm paper background, bigger touch targets, no animations.

v3-discord-dark — Discord Dark
Discord-style dark: dark grey background, blurple buttons, rounded message bubbles.

v4-discord-light — Discord Light
Same Discord-style layout as dark, but light theme.

v5-big — Big & Bold
Much larger fonts, chunky buttons, big touch targets, generous spacing.

v6-minimal — Minimal
Lots of whitespace, thin hairline dividers, small quiet grey text, almost no boxes.

v7-retro — Retro Terminal
Monospace everywhere, green-on-black terminal feel, square corners.

v8-pastel — Pastel Soft
Soft pastel colors, fully rounded corners, friendly and light.

v9-compact — Compact
Smaller fonts, tight spacing, more messages visible at once.

v10-contrast — High Contrast
Extra-large bold text, maximum contrast, clear focus outlines, big tap targets.
